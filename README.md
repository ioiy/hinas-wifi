# HiNAS WiFi 控制面板 (IOIY 定制增强版)

专为海思机顶盒 (如 Hi3798MV100 / E酷 NAS 等) 打造的终端可视化 WiFi 管理工具。
告别繁琐的 Linux 命令行，一键傻瓜式完成 WiFi 驱动安装、网络连接、防断流守护与进阶网络配置！

## ✨ 核心功能

- 🔌 **智能驱动安装**: 自动检测 USB 硬件芯片 (RTL8188ETV/FTV)，一键下载注入驱动
- 📡 **可视化扫描与连接**: 全中文界面，扫描附近 WiFi，连接后自动验证网关+外网连通性
- 🔑 **WiFi 密码查看**: 列出所有已保存 WiFi 及密码，忘记密码不用翻配置文件
- 🛡️ **防掉线守护 (watchdog v3.5)**: ping-only 监控，正常时不碰驱动，断线才四级恢复
- 📊 **断网统计面板**: 记录断网时间/原因/恢复耗时，支持今日 vs 昨日对比
- 🔄 **定时重连**: 每天指定时间自动重连 WiFi，预防驱动内存泄漏
- 🌐 **网络详情状态**: MAC/IP/网关/DNS/公网 IP 一览
- 📌 **静态/动态 IP 切换**: 锁定静态 IP 防路由器重启丢机器
- 🚀 **WiFi 热点 (AP)**: NAS 变路由器，开启后自动显示 SSH 登录地址
- 📱 **热点客户端列表**: 查看已连接设备的 IP/MAC/主机名
- 🔋 **省电模式开关**: RTL8188FU 省电控制，实测开启更稳定
- 🌐 **IPv6 模式开关**: `ignore`/`auto`/`disabled`，解决 IPv6 拖垮 DHCPv4
- 🔒 **BSSID 锁定/解除**: 双 AP 同名 SSID 防漫游互踢
- 📶 **多 WiFi 优先级**: 按优先级自动切换，支持按信号强度一键排序
- 🆘 **自动热点救生通道**: 无 WiFi 连接超时自动开热点，定期探测恢复，参数全可配置
- 🩺 **一键诊断报告**: 收集网络/驱动/日志/统计打包 txt，方便远程排查
- 📏 **网络测速**: 国内 (腾讯/阿里 CDN) / 国外 (Cloudflare/tele2) / 双向对比
- 🔄 **一键热更新**: 在线检测更新，同版本支持强制替换
- ⚡ **全局快捷指令**: 任意目录输入 `wifi` 秒开面板

## 📥 安装与运行

```bash
cd /root
wget -O hinaswifi.sh https://ghfast.top/https://raw.githubusercontent.com/ioiy/hinas-wifi/main/hinaswifi.sh
chmod +x hinaswifi.sh
./hinaswifi.sh
```

运行一次后，任意目录输入 `wifi` 即可打开控制面板。

## 🆘 自动热点救生通道 (v2.3.1)

### 解决什么问题

headless 盒子搬到新环境，没有已保存 WiFi，没有网线 → 彻底失联。

### 工作原理

```
盒子无 WiFi 连接
  → watchdog 先尝试重连已保存 WiFi (每 1 分钟)
  → 超时阈值 (默认 10 分钟) 内连不上
  → 自动开启热点 (默认 SSID: HINAS, 密码: 88888888)
  → 手机连热点 → SSH 登录盒子 (地址自动显示)
  → 运行 wifi → 网络连接 → 扫描连接新 WiFi
  → 连上新 WiFi → 热点自动关闭

路由器重启场景:
  → 断网 → 10 分钟后开热点
  → 路由器恢复 → 热点中每 6 分钟探测一次
  → 探测关热点 → 尝试连已保存 WiFi → 成功 → 自动切回 ✅
```

### 可配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 热点名称 | `HINAS` | 手机可搜索到的 SSID |
| 热点密码 | `88888888` | WPA 密码 (至少 8 位) |
| 超时阈值 | 10 分钟 | 无 WiFi 连接多久后开热点 |
| 检测间隔 | 2 分钟 | 后台检查频率 (crontab) |
| 探测间隔 | 6 分钟 | 热点运行时多久尝试重连已保存 WiFi |

## 🐛 已解决的问题

1. **watchdog 过度干预驱动** → v1.9.7 ping-only
2. **IPv6 拖垮 DHCPv4** → v2.1.0 `ipv6.method=ignore`
3. **双 AP 同名 SSID 漫游冲突** → v2.2.0 BSSID 锁定
4. **无网线环境下盒子失联** → v2.3.1 自动热点救生
5. **菜单颜色代码裸露** → v2.3.1 修复 `echo` 缺少 `-e`
6. **DNS 测速报"全部无响应"** → v2.3.1 用 `awk` 替代 `bc`
7. **网络测速 N/A** → v2.3.1 换国内 CDN + 国外 Cloudflare
8. **同版本无法更新** → v2.3.1 增加"强制替换"选项
9. **连接成功但实际没网** → v2.3.1 连接后自动 ping 网关+外网验证
10. **热点 IP 写死** → v2.3.1 从 nmcli 自动读取实际 IP
11. **扫描卡死** → v2.3.1 加 timeout 保护
12. **备份不含自动热点** → v2.3.1 备份增加 auto_hotspot 配置和脚本
